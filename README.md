### O que aprendi com este projeto:
Aprendi que uma cobertura de código de 100% pode trazer uma falsa sensação de segurança, pois ela apenas garante que as linhas foram executadas, mas não que a lógica está correta. O teste de mutação é essencial para validar a real eficácia e a qualidade dos nossos asserts
